# Exercise images

Start/end photos for the bodyweight exercise library (`features/exercise/library.ts`).

Photos sourced from free-exercise-db (github.com/yuhonas/free-exercise-db), which is published under the Unlicense. The original photo source and its terms have not been independently verified.

Regenerate with `npm run exercise:images` (fetches only the listed images from GitHub raw). Pass a local checkout path or another base URL as the first argument to use a different source. `placeholder.svg` is shown for moves with no photo.
